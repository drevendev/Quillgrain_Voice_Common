# Synthetic scenario

Оригинальное понятийное объяснение синтетического приложения для читателя, который знает слово «файл». Локальное сохранение записывает изменения на этом устройстве. Синхронизация передаёт сохранённые изменения на другое устройство при подключении к сети. Без сети локальное сохранение доступно, синхронизация ждёт подключения. Объяснить различие без метафор и обещания резервного копирования. Повтор терминов нужен для однозначности.

# Editorial demonstration

Локальное сохранение и синхронизация выполняют разные действия. Локальное сохранение записывает изменения на том устройстве, где вы работаете. Синхронизация передаёт сохранённые изменения на другое устройство, когда есть подключение к сети.

Поэтому без сети можно сохранить файл локально. Чтобы изменения появились на другом устройстве, нужно дождаться подключения и синхронизации. Локальное сохранение само по себе этого не делает.
