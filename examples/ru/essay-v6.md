# Synthetic scenario

Оригинальное понятийное объяснение синтетического приложения для читателя, который знает слово «файл». Локальное сохранение записывает изменения на этом устройстве. Синхронизация передаёт сохранённые изменения на другое устройство. Подключение к сети — необходимое условие синхронизации; порядок её запуска и факт выполнения не сообщены. Без сети локальное сохранение доступно. Объяснить различие без метафор, обещания резервного копирования и вывода об автоматической передаче. Повтор терминов нужен для однозначности.

# Editorial demonstration

Локальное сохранение и синхронизация выполняют разные действия. Локальное сохранение записывает изменения на этом устройстве; для него сеть не нужна. Синхронизация передаёт сохранённые изменения на другое устройство и требует подключения.

Без сети файл можно сохранить локально. Но и само подключение ещё не означает, что изменения уже переданы: наличие необходимого условия и выполнение действия — разные вещи. Локальное сохранение само по себе изменения на другое устройство не передаёт.
